# MBAS 八字命盤解讀專家系統 v2.1.0

繁體中文靜態網站。出生資料下拉選單、詳細四柱、五大報告分類與全部規則運算均在瀏覽器執行；不串接 AI、API 金鑰或後端。可部署至 GitHub Pages。

本次只修改系統，不附命主的新報告或 PDF。本次主要變更見 [2.1.0更新紀錄](docs/UPDATE_2.1.0.md)，子平格局功能見 [2.0.0更新紀錄](docs/UPDATE_2.0.0.md)，測試見 [驗證紀錄](docs/TEST_RESULTS.md)。

## 2.1.0 主要更新

- 新增《子平真詮》月令格局判讀層，以月令本氣、透干、藏干及十神生剋判斷命格運作方式。
- 可辨識正財、偏財、正官、七殺、正印、偏印、食神、傷官、建祿、月劫及陽刃等月令格局。
- 四柱資訊下方新增「月令格局解讀」，以一般人能理解的文字說明格局、參與力量與發揮關鍵。
- 古典月令格局用神與五行喜用神維持獨立裁決，避免兩種不同概念互相覆蓋。
- 新增結構化貴人判斷：先依格局需要與主病救應辨認人物作用，再以天乙輔助，並逐年區分遇見新人、既有人脈啟動及取得正式授權。
- 五行使用卡明確標示今年唯一第一順位及後續配合順序，不再讓多個五行同時宣稱優先。
- 手機四柱改為年、月、日、時由上而下排列，每柱內容由左至右呈現，不使用橫向捲動條。
- 本次變更與實際驗證見 [2.1.0更新紀錄](docs/UPDATE_2.1.0.md)。未重新產生或匯出命主報告。

## 開發與檢查

需 Node.js >=22.12，部署工作流程使用 Node 22。

```bash
npm ci
npm run dev
npm run check
```

`check` 依序執行單元／介面測試、36,000組運年遍歷、正式建置、子路徑HTTP檢查。`npm run docs:rules` 由版本化規則生成維護索引。`npm run preview` 可預覽正式產物。

ZIP包含 `src/`、`tests/`、`scripts/`、`docs/`、鎖定依賴、`.github/workflows/deploy.yml`及本次 `dist/`。不含node_modules。請以HTTP開啟，不要直接雙擊file協定的index.html。Git忽略dist，由Actions重新建置。

## 更新與GitHub Pages

現有專案請看 [Windows更新步驟](docs/UPGRADE_WINDOWS.md)。覆蓋程式內容並保留原本的 `.git`，不用清空GitHub。

儲存庫 **Settings → Pages → Source → GitHub Actions**。推送main後，既有流程執行npm ci、單元測試、運年遍歷、建置與子路徑檢查，成功後部署dist。也可在Actions手動執行。

Vite採 `base: './'` 與hash導覽，支援專案儲存庫子路徑。保留31個出生地點、1901–2026年輸入、十步大運與出生年後110年的流年範圍。出生資料僅於目前分頁以sessionStorage暫存；重新整理使用目前版本重算。

## 排盤與起運慣例

年柱以立春，月柱以12節實際交接時刻；astronomy-engine 2.1.19計算太陽黃經。出生地法定時間採內附moment-timezone 0.6.0資料，拒絕DST不存在或重複時間。00:00換日，23:00–00:59子時，不修正真太陽時。

陽男陰女順行、陰男陽女逆行，以年干陰陽決定。順行取下一節，逆行取前一節；精確交節時前節含當下、後節嚴格晚於當下。UTC時間差按三日一年、一日四個月、一小時五日換算，30日月拆成年月日秒，再按出生地曆日加算。大運十曆年，不用3650日代替；交運流年按實際時刻分段。介面有完整簡明依據。

## 規則範圍

使用月令、藏干透干、根氣、干支作用、五種組合結構、格局缺陷、承載、病藥、位置接續、氣勢與寒暖燥濕四類調候；喜忌不以五行數量或缺失直接裁決。

此為可檢查的工程規則模型，仍有明訂係數與閾值；從格、專旺、化氣改盤及完整十干逐月古典調候尚未擴充。組合測試不等於命理預測準確度驗證。詳見 [規則索引](docs/RULES.md) 與修正紀錄中的實作邊界。

「匯出 PDF」會開啟瀏覽器列印功能；實際紙張分頁仍需在使用者的字型、縮放及印表機設定下預覽。此次未代替使用者產生命盤PDF。
