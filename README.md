# MBAS 八字命盤解讀專家系統 v3.1.0

繁體中文靜態網站。出生資料下拉選單、詳細四柱、五大報告分類與全部規則運算均在瀏覽器執行；不串接 AI、API 金鑰或後端。可部署至 GitHub Pages。

本次只修改系統，不附命主的新報告或 PDF。PDF 下載功能見 [3.1.0更新紀錄](docs/UPDATE_3.1.0.md)，規則架構見 [3.0.0更新紀錄](docs/UPDATE_3.0.0.md)，測試見 [驗證紀錄](docs/TEST_RESULTS.md)。

## 3.1.0 主要更新

- 「匯出 PDF」改為直接產生並下載檔案，不再開啟瀏覽器列印視窗。
- PDF 仍包含命盤總覽與五章完整內容，並自動依出生日期命名。
- 產檔全程在瀏覽器本機完成，不上傳出生資料或報告內容。

## 3.0.0 主要更新

- 全章改用同一份十五步命局判斷，統一格局、主病、承載、喜用與歲運結果。
- 建立 131 個有限有效組合及 393 個穩定文本版本；未覆蓋組合為零。
- 貴人角色分成「容易遇到、幫助最大、正式位置、機會伴隨成本、表面支持增加責任」五類。
- 貴人年份改按過往、未來十年與各步中長期大運分組，不再全人生混合排名。
- 加入天干生、地支半合與破、伏吟、反吟及三合／三會分判；單一十神或神煞不直接斷重大事件。
- 財務問題直接對應價格、驗收、分潤、預算、所有權、回款、決策及退出條件。
- 報告自動檢查完整句、十二字長片語與相鄰段落開頭，文本選擇保持可重現。

## 開發與檢查

需 Node.js >=22.12，部署工作流程使用 Node 22。

```bash
npm ci
npm run dev
npm run check
```

`check` 依序執行單元／介面測試、131組規則覆蓋檢查、36,000組運年遍歷、正式建置、子路徑HTTP檢查。`npm run docs:rules` 由版本化規則生成維護索引。`npm run preview` 可預覽正式產物。

ZIP包含 `src/`、`tests/`、`scripts/`、`docs/`、鎖定依賴、`.github/workflows/deploy.yml`及本次 `dist/`。不含node_modules。請以HTTP開啟，不要直接雙擊file協定的index.html。Git忽略dist，由Actions重新建置。

## 更新與GitHub Pages

現有專案請看 [Windows更新步驟](docs/UPGRADE_WINDOWS.md)。覆蓋程式內容並保留原本的 `.git`，不用清空GitHub。

儲存庫 **Settings → Pages → Source → GitHub Actions**。推送main後，既有流程執行npm ci、單元測試、運年遍歷、建置與子路徑檢查，成功後部署dist。也可在Actions手動執行。

Vite採 `base: './'` 與hash導覽，支援專案儲存庫子路徑。保留31個出生地點、1901–2026年輸入、十步大運與出生年後110年的流年範圍。出生資料僅於目前分頁以sessionStorage暫存；重新整理使用目前版本重算。

## 排盤與起運慣例

年柱以立春，月柱以12節實際交接時刻；astronomy-engine 2.1.19計算太陽黃經。出生地法定時間採內附moment-timezone 0.6.0資料，拒絕DST不存在或重複時間。00:00換日，23:00–00:59子時，不修正真太陽時。

陽男陰女順行、陰男陽女逆行，以年干陰陽決定。順行取下一節，逆行取前一節；精確交節時前節含當下、後節嚴格晚於當下。UTC時間差按三日一年、一日四個月、一小時五日換算，30日月拆成年月日秒，再按出生地曆日加算。大運十曆年，不用3650日代替；交運流年按實際時刻分段。介面有完整簡明依據。

## 規則範圍

使用月令、藏干透干、根氣、干支作用、五種組合結構、格局缺陷、承載、病藥、位置接續、氣勢與寒暖燥濕四類調候；喜忌不以五行數量或缺失直接裁決。身勢標示包含極弱至極強、從弱、從強、假從與專旺，但仍由同一套結構及承接證據裁決，不因名稱直接套用固定喜忌。

此為可檢查的工程規則模型，仍有明訂係數與閾值；合化只列保守候選，不自動改換日主。組合測試不等於命理預測準確度驗證。詳見 [規則索引](docs/RULES.md) 與修正紀錄中的實作邊界。

「匯出 PDF」會在瀏覽器本機整理完整五章並直接下載 PDF，不需要設定瀏覽器頁首頁尾。
