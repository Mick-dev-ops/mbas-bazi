# 參考報告章節對照與內容修正

此文件供維護者複核。命主網頁與列印只顯示解讀結論，不顯示規則、分數或本文件。

| 參考報告的內容命題           | 本系統正式章節                           | 內容要求                                                     |
| ---------------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| 真正性格、隱藏一面與自我壓力 | 第一章真實性格、內在拉扯、壓力反應       | 分開外在行為、評價時反應與超載後代價                         |
| 核心武器與能力組合           | 第一章核心優勢與能力組合                 | 說明能在哪類實際工作發揮，以及何時變成負擔                   |
| 財富發展與收入來源           | 第二章財富發展潛力、收入進來的方式       | 先下整體結論，再解釋專業、正式位置或專案如何形成收入         |

| 伴侶檔案與接近方式           | 第三章伴侶特質與相遇方式                 | 寫可觀察的互動特質；不編造外貌、職業、身分                   |
| 戀愛反覆循環                 | 第三章戀愛模式與關係問題                 | 描述吸引、相處、壓力與未說出口的期待                         |
