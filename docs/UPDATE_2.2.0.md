# 2.2.0 大運發展重點差異化

## 版本定位

本版改善既有大運敘事功能，屬於小功能調整，因此次版本由 2.1.0 提升為 2.2.0。

## 原因

原程式雖已計算各步大運的干支、十神與合沖作用，最後卻先壓縮成「重整、競爭、支出、定案、擴張」五種模式，再套入固定開場。多個不同大運因此反覆出現「重新安排順序」或相近句型，掩蓋底層計算原本具有的差異。

## 修改方式

- 大運第一句改由大運天干對本命日主的實際角色產生，分成十種作用，不再由五種模式決定。
- 大運地支主氣作為第二層生活影響；天干與地支角色不同時，補充兩者共同形成的主題。
- 再依實際合沖刑害、日主承接能力、當期最需要的力量、當期限制及原局核心問題是否轉向，決定第二句。
- 童年、成年與晚年分別使用學習、自主生活、家庭支持與晚年安排等相符情境。
- 每一步只保留最重要的一至兩項內容，避免冗長及命理術語。
- 同一干支放入不同日主或格局時會重新計算，不使用出生日期、姓名或特定四柱例外。
