# 1.5.0 財務階段與置頂總評

日期：2026-10-29（Asia/Taipei）。以本次附件定位問題，只更新系統，不附新命盤報告或PDF。

## 問題與修正

1. 舊程式 `financeConclusions` 將60歲後統一為熟齡三句，`annualFinanceDelta` 又將不同年度作用覆寫成這三句，造成70與80歲、不同大運流年看來相同。本版刪除這兩層年齡覆寫；新的 `report/finance-story.js` 將年齡作為財務情境，而不是抹掉命理作用的終點。
2. 財務階段分界為12、18、25、35、45、55、60、70、80、90實足歲；生日以出生地法定時間切分，跨界大運及流年保留分段。70歲段重款項可用性與調度，80歲段重支付、代辦及本人決定，90歲段重支付接續；不假定已退休、持有房產或有子女代管。
3. 財務描述採實際原局＋大運＋流年計算出的受剋十神、根氣受擾、食傷財及財官接續、承格與主病轉向。年度只選當年介入的財務主題，大運則對比原局。最多三項年度主題，同一機制不重複挑選。各主題保留實際參與干支的短依據。
4. 五頁新增獨立 `overview`，在年份選單、細節卡及表格之前顯示。本質、財運、緣分、大運流年、五行都有大局總評，並進入現有列印與JSON輸出。
5. 財運總評先回答收入能否開展、留財瓶頸、累積方式及具接續條件的大運階段。刪除與置頂總評重複的「財富發展潛力」卡；下方直接進收入、可用餘額、支出與時間線。

## 主要檔案

- `src/report/finance-story.js`：新增年齡情境、實際財務作用選題、原局財運總判斷。
- `src/engine/finance.js`：保留財務機制判斷，刪除年齡整段覆寫及已停用的年度拼接器。
- `src/report/period-story.js`：財務描述改用新組合器；既有一般發展、緣分及五行規則保持原職責。
- `src/report/client.js`：細分年齡與生日分段、五頁總評、整體財運與時間線。
- `src/main.js`、`src/style.css`：置頂總評的畫面／列印、頁尾v1.5.0。
- `tests/finance-stages.test.js`：新增階段、命盤／運年差異、總評與去重案例；既有相關案例同步更新。
- `package.json`、`package-lock.json`、`src/data/constants.js`：版本同步。原局用神與曆法演算法沒有針對本次命主改寫。
