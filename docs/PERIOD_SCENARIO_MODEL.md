# 1.4.0 大運背景與流年差量模型

原局＋大運是背景；原局＋大運＋流年是當期。兩者均使用同一套事實、承載、格局、病藥、氣勢、調候與用神裁決。不永久鎖定原局忌神，也不覆寫原局裁決。

`periodThemes` 年度主題只取涉及年度柱的作用及相較背景的主病轉向，區分新增與同語義加強，按重要性選一至三項。天干剋須看實際受剋端及其十神；日干參與不是夫妻宮事件。刑害的近似結果依語義去重，合化審查不另作事件。完整三合三會只表示流向條件，不自動化局。

`annualFinanceDelta` 分收入、餘額、支出三機制比較背景與當期，並辨識新加入的產出到財、財到官殺、直接制財與印制食傷。未轉向時說明延續，不重印整段大運財務背景。未成年與熟齡採不同生活語境。

相鄰年比較：有實際西元年時，以前後年立春所處大運各自計算；交運年保留實際分段。僅假設干支組合時，文字明示同一大運背景。沒有隨機換詞、年份雜湊或固定某年特例。

`elementGrowth` 以當期實際五行載體、十神、生剋對象、核心之病、承格與用神條件，說明再增加後的功能及副作用。制官、財生殺、財破印與印制食傷分開處理；不得將某元素制約另一元素概括成所有外部要求減少。

原局順序、實際操作順序、當期順序分開。主要標籤不重疊；格神及相神承接功能保留為結構身分。未有細分依據的同層排序明示為顯示次序，不聲稱精確高下。

遍歷包含10種日主、60假設大運×60流年，共36,000組；不是宣稱該命主會經歷全部假設大運。歷史資料中的100功能配對、15個敘事入口僅作資料完整性檢查，1.4.0年度閱讀內容由實際作用及差量決定，不再用該配對表直接拼段落。數字不代表已涵蓋所有傳統命格。
