# 1.6.0 人生本質與生活導向

## 問題定位

附件報告的「本質」總評與前三節大量沿用專業、成果、交付、需求、收入、權責等財運／職涯語彙。原因不是單一句模板，而是底層 `worldRule`、本質章、月柱宮位翻譯與五行功能翻譯都將人的價值集中在工作表現。

## 修改內容

- `src/report/life-story.js`：新增整體人生敘事器，依月令十神、相助十神、日支內在需求、承格狀態、根氣集中、格局與主病，共同產生人生本質、核心需要、優勢、壓力反應、反覆課題、快樂來源、恢復方式及早年／成年／中年／晚年的生活配置。沒有姓名、生日或特定四柱分支。
- `src/engine/analyze.js`：唯一人生主線由交付、交易、位置改為身心安頓、個人選擇、關係、承諾比例與生活餘裕；格局仍參與判定，但工作不再是人生總目標。
- `src/report/client.js`：本質頁改為五個人生主題，不再引用財運結論；大運章由「主導權提升」改為「自主選擇與生活主導權」；大運總評先寫生活與關係，再補充財務。
- `src/data/period-scenes.js`、`src/report/period-story.js`：成年與熟齡情境改為自主、同輩、興趣、表達、生活體驗、承諾、壓力、休養與內在整理。月柱不再固定翻譯為「工作位置與日常職務」。
- `src/report/templates.js`、`src/engine/period-context.js`：五行的日常運用改寫為人際界線、創作表達、時間金錢選擇、生活承諾、理解休養與支持。財務機制仍留在財運頁，不影響既有喜用神裁決。
- `tests/client-report.test.js`、`tests/ui.test.js`：加入本質五節、生命週期、不同命盤差異及禁止職涯語彙回流的回歸條件。

## 驗證

- 正式 Vite 建置成功，39 個模組完成轉譯。
- 以四張不同命盤直接執行報告生成：本質總評各不相同；每張皆有五個人生主題與早年、成年、中年、晚年配置；本質頁不含工作、職務、交付、收入、報酬或升任語彙。
- 直接檢查 2026 流年內容，不再出現「工作位置與日常職務」舊宮位翻譯。
