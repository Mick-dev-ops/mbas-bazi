# 3.0.0 共用裁決、貴人時間表與規則覆蓋

本版是規則架構大改，版本由 2.2.0 升為 3.0.0。系統仍是純前端規則引擎，不串接 AI 或後端，也不替任何特定出生資料寫例外。

## 問題、原因與修改

| 原有問題                               | 原程式原因                                      | 3.0.0 修改                                                                   |
| -------------------------------------- | ----------------------------------------------- | ---------------------------------------------------------------------------- |
| 各章格局與喜用可能使用不同名稱         | 子平摘要、原局分析與歲運各自整理結果            | 新增 `decision-model.js`，所有章節共用十五步結果；子平名稱改引用同一月令格局 |
| 貴人「容易遇到」與「幫助最大」混在一起 | 所有候選角色只按單一分數排序                    | 拆成五種人物判斷，各自排序並保留十神功能狀態、限制與辨認方式                 |
| 晚年高分年份排擠近期                   | 一生年份混在同一分數池，只取八筆                | 分成近十年回顧、未來十年、中長期逐運；每運分別保留高／中／觀察               |
| 天乙、官、印出現便容易被寫成貴人       | 年份加分缺少完整的環境與承接門檻                | 必須同時有本盤所需角色、大運環境、流年引動、未失效及可承接；天乙只輔助       |
| 流年大運大量共用開頭                   | 固定 `PERIOD_LEAD`、`MONEY_LEAD` 疊在每年內容前 | 移除固定前綴，只保留當年新增、加強或轉向的實際作用                           |
| 財運問題與改善做法未直接對應           | 財務機制只產生判斷，未產生條件清單              | 新增價格、驗收、分潤、預算、所有權、回款、決策權與退出條件對照               |
| 干支作用種類不足                       | 原引擎未明列天干生、半合、破、伏吟及反吟        | 補齊作用並把三合、三會分開；所有作用仍需判斷功能，不直接斷事件               |
| 起運顯示原始秒數                       | UI 直接輸出餘秒                                 | 改顯示年、月、日、小時、分、秒                                               |
| 相同句與長片語重複                     | 報告沒有輸出後品質檢查                          | 新增穩定去重及完整句、十二字片語、相鄰開頭檢查                               |

## 規則覆蓋

- 身勢：11 組。
- 格局狀態：7 組。
- 十神功能：10 × 8，共 80 組。
- 干支作用：20 組。
- 歲運狀態：13 組。
- 有限有效組合總數：131。
- 已覆蓋：131。
- 未覆蓋：0。
- 每組有規則 ID、成立與排除條件、優先序、共存與互斥欄位、衝突裁決、適用章節、文本 ID、替代文本及上位回退。
- 131 組各有一組主文本及兩組替代視角，共 393 個穩定文本版本。

覆蓋範圍只計系統實際支援、經正規化後可成立的狀態，不把互斥或命理上不可能同時成立的笛卡兒積列為有效組合。

## 報告文字

- 本質：10 種月令生活傾向、7 種核心壓力各三種觀察角度、5 種結構人生主線。
- 財運：4 種收入、4 種留財、4 種支出及 12 組直接改善條件。
- 緣分與貴人：10 種關係傾向、10 種貴人人物作用、5 種人物排名、3 段時間表。
- 流年大運：10 種角色 × 3 種生活背景、25 種功能配對、干支作用與原局／大運／流年轉向文本。
- 五行：5 種相對日主功能，每種含使用前、使用後、過少、適中、過量及生活做法。

## 禁止的單條件推論

`inference-guards.js` 明列 16 項禁用捷徑，包括以五行多寡定喜忌、身強身弱固定取用、月令十神等於成格、見合沖直接斷事件、見財官印食傷或天乙直接斷進財／升職／師長／貴人，以及只按年齡套事件。

## 相容性

- 保留出生資料下拉選單、詳細四柱、五頁報告、純規則運算與 PDF 列印。
- Vite 使用相對資產路徑與 hash 導覽，維持 GitHub Pages 使用者站及專案子路徑相容性。
- GitHub Actions 增加規則覆蓋檢查，仍以 Node 22 執行測試、完整運年遍歷、建置及正式產物 HTTP 檢查。
