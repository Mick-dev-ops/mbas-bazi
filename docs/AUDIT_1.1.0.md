## 根因與責任界線

第一，舊 `capacity` 將所有財官食傷合併為負荷，用印比與負荷比直接判承格。這不是已驗證的旺衰模型；它把食傷生財的可用功能也算入負荷，無法獨立處理得地、同類根與透干承接。舊報告雖列出四處同類藏根，結果仍被單一比值決定。

第二，`diagnose` 將承格不足固定列最高程度，`adjudicate` 又對同一印星給主病、次病與扶身的重複獎勵。錯誤前提因此在多模組反覆被放大。印制食的風險只有小額扣分，無法排除不適合的核心候選。

第三，舊版甚至會因比劫聚合量高於財就列比劫奪財，沒有要求其妨礙主結構的具體作用。這次要求財相關結構及剋財對象證據，不由數量關係單獨判病。

第四，舊測試多數確認算式、流程一致與輸出存在，沒有這張盤及其反向案例的專家裁決對照。67 項通過不能證明命理解讀正確；五頁一致也可能只是五頁一致地引用錯誤。

第五，舊文字過度依賴作用力最高的單一十神及固定五行行為類比。這次改由結構、承格、主病、兩項以上十神及宮位生成章節，並讓五行運用回扣各自的實際救應與風險。

## 本次實作方式

分析先建立月令及格局的結構假說，再初判損傷與救應；承格、流通與調候覆核後，形成唯一母分析。中途修正假說會保留在 `analysis.pipeline`，最終五頁只引用同一母分析，不各自選用神。

承格的根氣覆核條件為：原局有效本氣根至少三處、作用後合計根力至少 1.2、包含日支本氣根、比劫透干作用力至少 .5、原有輔助比值至少 .6。這些是明訂的保守工程門檻，尚未經跨學派專家樣本校準，不能宣稱是唯一古法。根多本身不會直接產生主病或喜忌。

本例只有同時具備財相關主結構、上述承接證據，及月干壬水受相鄰戊土剋的作用資料時，才啟動 `wealth-channel`。水直接保護交易承接，木作疏制配合，金保留食傷生財。火生比劫並制食、土加重制財，列入結構排除。這是一般條件規則，沒有比對命主姓名、生日或四柱字串的特例。

取用不再累加五行功能分。每個候選保存 `decisionPath`，包含直接救應、制化配合、相神、通關、調候的來源與序位。沒有直接主病救應候選時，核心用神可為空；不因最少、缺失或數量平均而強選。資料欄位 `score` 僅為舊匯出相容保留的序位編碼，不參與排序，非五行強度或可信度。

角色屬性顯示成立條件及限制，不給無根據分數。世界規則由主結構、承格、主病與流通共同生成。每個五行另列先改變面向、能力、資源、使用條件、可能變化、確認方式與過量副作用。
