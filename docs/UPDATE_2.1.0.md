# 2.1.0 結構化貴人運判讀

## 版本定位

本版在既有緣分章新增可供報告共用的結構化貴人判斷，屬於小功能新增，因此次版本由 2.0.0 提升為 2.1.0。

## 主要變更

- 以原局格局、命局需要與十神作用判斷真正有幫助的人物類型。
- 將天乙貴人作為輔助訊號，不再看到吉星就直接判定貴人運旺。
- 區分遇見新人、既有人脈開始協助，以及取得具體授權或支持。
- 新增貴人時間表，呈現年份、年齡、大運、人物類型、簡短依據與限制。
- 不以陰陽干支直接推斷貴人性別；無可靠規則時明確說明無法判定。
- 加入不同日主、格局及大運的差異測試，確認人物類型與年份排序會隨命盤改變。
