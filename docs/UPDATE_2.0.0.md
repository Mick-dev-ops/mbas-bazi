# 2.0.0 子平月令格局判讀

## 版本定位

本版新增獨立的月令格局判讀能力，已超出原有文案與介面微調範圍，因此主版本由1.9.0提升為2.0.0。

## 核心變更

- 新增 `src/engine/ziping.js`，以月令本氣、藏干透出及十神生剋建立古典格局判讀。
- 一般格局依月令藏干透出定位；建祿、月劫與陽刃仍以月令本氣定位，不因其他藏干透出而改名。
- 依財、官、印、食、殺、傷、祿劫與陽刃的不同運作條件，組合格局來源、其他十神參與及發揮關鍵。
- 四柱下方新增「月令格局解讀」，只顯示簡短命盤依據與生活化結論。
- 古典月令格局用神不直接改寫原有五行喜用神排序；兩者分別回答「命局如何運作」及「五行如何調整」。
- 五行使用卡改為單一第一順位、第二順位配合、第三順位後續及第四／第五順位節制。
- 手機四柱採縱向四列，各柱內容橫向閱讀，移除水平捲動條。
