# 1.7.2 財運時間線改按大運分段

## 問題

財運頁的「財運轉折與大運時間線」仍使用舊的年齡切段函式。同一步大運會在12歲、18歲、25歲、35歲、70歲、80歲等年齡再次切割，造成同一大運出現多列，也讓讀者誤以為人生階段本身就是新的行運。

## 修改

- 財運總覽改用與流年大運頁相同的 `clientLuckCycle()`，每一步實際大運只產生一列。
- 移除「人生階段」欄位，保留期間、年齡、大運及財務發展。
- 財務敘述仍由原局、大運及財務機制動態產生，不把不同大運合併成相同固定文字。
- 財運頁的逐年表與單年卡片不再因生日或人生階段拆段；只有年度內實際交運時才分成換運前後兩段。
- 內部年齡情境翻譯仍保留，用於讓兒童、成年與高齡的用語合理，但不再拿來切割公開時間線。

## 驗證

- 財運總覽列數等於命盤實際大運數，各大運干支只出現一次。
- 表頭為「期間、年齡、大運、財務發展」，不再包含「人生階段」。
- 正式建置及正式產物頁面確認後交付；依使用者要求不執行完整 `npm test`。
