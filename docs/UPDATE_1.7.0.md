# 1.7.0 本質總評與十年大運分段

## 問題與原因

1.6.1 雖讓本質總評與第一張卡片的結論字串不同，但兩者仍共用 `life.conclusion`、`life.coreNeed` 與 `life.lifeRule` 的主要內容，因此閱讀上仍是重複。

流年大運總覽直接使用財運頁的 `lifeSlices()`。該函式為了呈現不同年齡的財務情境，會在12、18、25、35、45、55、60、70、80、90歲切段；同一大運的命理背景沒有改變，卻被拆成多列，造成發展重點重複。

## 修改

- 新增 `clientLuckCycle()`：每一步大運只產生一筆十年背景，以實際交運起迄日、該運干支、原局與大運作用生成發展重點。
- 流年大運總覽及選定大運卡片改用 `clientLuckCycle()`，不再使用財務年齡切段。
- 一般流年逐年表只沿用 `annualReport()` 的實際換運分段；財運逐年表才繼續使用年齡財務階段。
- 本質總評新增獨立的 `life.overview` 與 `life.overviewPractice`。總評回答「這一生怎麼活」，第一張卡片回答「這個人本質上是誰、需要什麼」，不再共用句段。
- 未修改排盤、起運、喜用神、財務作用、緣分或歲運生剋裁決。

## 驗證範圍

- 本質總評結論及段落均不等於第一張詳細卡片的內容。
- 大運總覽列數等於實際大運數，每個大運干支恰好出現一列。
- 範例第一步癸酉大運直接涵蓋2004-02-28至2014-02-28，不再切為9–11、12–17、18–19歲三列。
- 財運頁仍保留70、80、90歲等財務階段差異。
- 依需求未執行完整 `npm test`；未產生命主報告或PDF。
