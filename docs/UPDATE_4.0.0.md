# 4.0.0 更新摘要

本版是核心規則、貴人年份與 PDF 輸出的重大改版。

- `decision.core` 集中月令、透藏、日主承載、主輔格局、主病、救應、流通、調候、用神角色、三層五行順位與人生主線，各章只引用同一份結論。
- 貴人正式窗口必須同時通過命局需要、流年新增、外部人物成立與幫助落地；承接不足且無法被補足、嚴重受擾或只有事件時直接排除。
- 貴人表改為四欄，不固定保留年份，也不在正式報告顯示觀察候選。
- 每一流年使用年干、年支、所在大運及原局作用決定年度事件中心，相鄰年份不只替換年份名稱。
- 五行將長期順位、實際啟動順序與當期順位整合為一條操作流程；每項只顯示五個生活化欄位。
- PDF 直接建立文字與向量頁面，嵌入繁體中文字型；表格列避免切斷，跨頁重複表頭。
- 規則矩陣 139 組全部具有文本與上位回退規則。

本版沒有串接 AI 或外部命理 API，也沒有加入特定姓名、出生日期、四柱或年份的專屬答案。
