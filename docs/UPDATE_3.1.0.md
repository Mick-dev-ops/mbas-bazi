# 3.1.0 直接下載 PDF

本版為小功能更新，版本由 3.0.0 升為 3.1.0。命理規則、排盤、五章報告內容與 GitHub Pages 部署方式均未改變。

## 修改內容

- 「匯出 PDF」不再呼叫 `window.print()`。
- 瀏覽器會建立完整命盤總覽與五章報告的暫時內容，直接產生 PDF 並下載。
- 檔名格式為 `MBAS_八字命盤_YYYY-MM-DD_性別.pdf`。
- 匯出期間顯示處理狀態並暫停重複點擊；成功或失敗後都會移除暫時內容。
- PDF 採 A4 直式、15 mm 邊界，表格列與重要標題避免跨頁切斷。
- 所有處理均在瀏覽器本機完成，不傳送出生資料或報告內容。

## 主要檔案

- `src/ui/pdf.js`：PDF 設定、下載及檔名。
- `src/main.js`：建立完整報告、下載狀態與清理流程。
- `src/style.css`：離畫面 PDF 排版。
- `tests/ui.test.js`：直接下載、五章內容及不呼叫列印的回歸測試。
