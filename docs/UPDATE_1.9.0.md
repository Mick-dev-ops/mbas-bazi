# 1.9.0 報告精簡、緣分結論與手機四柱修正

## 問題與修改方式

| 問題                                         | 原因                                                     | 修改                                                                                       |
| -------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 財運與大運出現「年柱藏辛傷官、大運藏癸正財」 | 公開文字直接附加內部事件證據                             | 證據仍保留在規則資料中，但公開報告只顯示生活結論                                           |
| 財務發展與發展重點太長                       | 每段同時串入事件、證據、前後年比較與多項提醒             | 每一步大運限制為兩句內：第一句總評，第二句主要變化或風險                                   |
| 大運沒有點出重要轉變                         | 文字以十神管道為主，沒有先整理受影響的人生領域           | 依實際作用位置選出最多兩個領域，再判斷屬於明顯變動、反覆磨合、形成約定或方向擴展           |
| 緣分章沒有回答婚姻、子女、父母與貴人         | 原章節集中在相處模式，未建立年齡窗口與家庭關係規則       | 新增婚姻窗口、子女數量傾向與生子窗口、父母緣及貴人類型／階段；不以單一訊號保證事件一定發生 |
| 當年五行近似複製原局總評                     | 當期排序雖已重算，顯示層沒有翻譯流年與大運共同形成的障礙 | 先辨識當年與大運對原局造成的變動、磨合、綁定或壓力，再提出當期第一順位五行與具體做法       |
| 五行卡重複「整體」與「今年」                 | 同一組生活情境分兩次輸出                                 | 合併成一張卡，只保留一組使用前後、過少、適中、過多與生活做法                               |
| 工具列有下載按鈕與列印提醒                   | 沿用舊的JSON下載功能及提示文字                           | 移除下載報告與提示，只保留「匯出 PDF」及修改出生資料                                       |
| 手機四柱排成兩欄且高度凌亂                   | 540px以下強制改成兩欄                                    | 改成四柱單列並支援水平滑動，四柱順序及完整資訊不變                                         |

## 規則邊界

婚姻與生子年份採多條件窗口：配偶／子女訊號、相關生活位置、所在大運、流年互動與當期承受程度共同計算。系統輸出較可能的年齡區間，而不宣稱某年一定結婚、生育或保證精確子女數量。

## 修改檔案

- `src/report/period-story.js`、`src/report/finance-story.js`：公開事件與財務文字移除內部證據。
- `src/report/client.js`：兩句式大運短評、重要轉變、當年五行障礙及整合五行卡。
- `src/report/relationship.js`：婚姻、子女、父母及貴人規則。
- `src/ui/render.js`、`src/main.js`、`src/style.css`：移除命盤依據顯示、工具列及手機四柱版面。
- `tests/`：更新公開內容、緣分、五行整合、PDF工具列與差異化測試。

## 驗證

- 本次相關測試：4個檔案、50項全部通過。
